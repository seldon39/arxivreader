**Preview of arXivReader for Windows** (Windows 10 or 11, 64-bit). Same app as on the Mac; feedback is very welcome
in the [issues](https://github.com/seldon39/arxivreader/issues).

**Installation**: download `arXivReader-windows.zip`, right-click it → **Extract All…**, put the `arXivReader` folder
wherever you like (e.g. in Documents) and double-click `arXivReader.exe` inside it. Nothing else to install. The app
opens in a Microsoft Edge window of its own; your library is kept in `%LOCALAPPDATA%\arXivReader`.

**If Windows refuses to start it** ("Windows protected your PC"): the app is open source but not signed. Click
**More info**, then **Run anyway**. Your antivirus may also ask for confirmation the first time.

**Updates**: the app checks once a day for a newer Windows version. To update, quit arXivReader and replace the
`arXivReader` folder with the new one; your library is not in that folder and is kept.

**Not yet on Windows**: copying a library from another computer (File menu of the Mac app).

**Préversion d'arXivReader pour Windows** (Windows 10 ou 11, 64 bits). Installation : télécharger
`arXivReader-windows.zip`, clic droit → **Extraire tout…**, puis double-cliquer sur `arXivReader.exe` dans le dossier
`arXivReader`. Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires**, puis
**Exécuter quand même**. Mise à jour : quitter arXivReader et remplacer le dossier ; la bibliothèque, dans
`%LOCALAPPDATA%\arXivReader`, est conservée.
